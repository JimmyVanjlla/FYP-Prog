 5. IF THE DATA NEEDS REFRESHING (the morning of the presentation)
------------------------------------------------------------------------------
 After deploying, from the backend folder with the virtual environment active:

    python scripts/extend_demo_orders.py --base-url https://fyp-prog.onrender.com
    python scripts/prepare_demo.py       --base-url https://fyp-prog.onrender.com

 The first adds order history up to yesterday. The second adds the last 7 days of
 leftover logs, retrains forecasts (about a minute), reruns the leftover analysis,
 regenerates the "recommended to buy" list, and makes sure a purchase order, a
 delivery, a restock request and a weekly report for the 7 days ending today exist.
 Both are safe to run twice. A purchase order you approved is not recreated until
 you run the second script again, which adds a new pending one.
 Training only uses completed orders from finished days, so today's sample orders
 never distort the forecast.

 Cloud services on free plans: Supabase pauses after about a week without use
 and Redis deletes inactive databases. Opening the app once a few days before
 keeps both alive. If the app cannot log in, check the Supabase dashboard.
